# ระบบเลือกตั้งประธานรุ่น ปีการศึกษา 2569

## เปิดใช้ในเครื่อง

ใช้ Node.js 24 ขึ้นไป รันคำสั่งจากโฟลเดอร์โครงการ

```powershell
npm --prefix functions ci
node server.js
```

เปิด `http://127.0.0.1:8081/` แล้วเข้าสู่เมนู **ผู้ดูแลระบบ** ด้วยบัญชี Firebase Authentication ที่กำหนด claim `admin: true` ไว้แล้ว ระบบนี้ใช้ Firebase เฉพาะยืนยันบัญชีผู้ดูแล จึงไม่ต้องตั้ง Google Cloud Console, App Check, Cloud Functions หรือ Blaze สำหรับเซิร์ฟเวอร์ Node.js

ฐานข้อมูลที่ใช้งานบน Windows อยู่ที่ `%LOCALAPPDATA%\OracleElection2569\election.private.sqlite` เพื่อให้การบันทึก SQLite ไม่กระตุ้น Live Server ให้โหลดหน้าใหม่ หากพบฐานรุ่นก่อนในโฟลเดอร์โครงการ เซิร์ฟเวอร์จะคัดลอกข้อมูลเดิมไปใช้ในตำแหน่งใหม่ครั้งแรก หากยังไม่มีฐานรุ่นก่อน จะเริ่มจากไฟล์ `voters-import.private.json` ซึ่งมีทะเบียน 68 คนและสิทธิ์ในรอบที่ 1 ให้บันทึก **ผู้สมัครจริง** ก่อนตั้งเวลาเปิดหีบ ปิดหีบ และประกาศผลในเมนู **จัดการรอบ** ทั้งสามเวลากรอกเป็นเวลาไทย

นักเรียนใช้เลขประจำตัว 5 หลักและรหัสที่ประกอบด้วยเลขรุ่น 114 เลขห้อง และเลขที่สองหลักตามทะเบียน เซิร์ฟเวอร์ตรวจรหัสและออกโทเคนอายุสั้น การส่งบัตรเก็บเครื่องหมายใช้สิทธิ์กับยอดรวมในธุรกรรมเดียว รองรับนักเรียนต่างคนที่ส่งพร้อมกัน และปฏิเสธการส่งซ้ำของเลขประจำตัวเดิมในรอบเดียวกัน

หน้าแอดมินแสดงจำนวนผู้มีสิทธิ์ ผู้ใช้สิทธิ์แล้ว และผู้ยังไม่ใช้สิทธิ์จากเซิร์ฟเวอร์ทันทีที่บันทึกบัตรสำเร็จ เปิดเมนู **ทะเบียนและการใช้สิทธิ์** เพื่อดูรายชื่อคงเหลือหรือเปลี่ยนตัวกรองเป็นผู้ใช้สิทธิ์แล้ว หากติดตั้งหลังพร็อกซี HTTPS ให้ตั้งเส้นทาง `/api/admin/participation` ให้ส่งสตรีม SSE โดยไม่พักข้อมูลในบัฟเฟอร์

## เผยแพร่หน้าเว็บบน GitHub Pages

GitHub Pages เสิร์ฟไฟล์หน้าเว็บ ส่วนเซิร์ฟเวอร์ Node.js ต้องเปิดอยู่ที่ปลายทาง HTTPS ที่อุปกรณ์นักเรียนเข้าถึงได้ ในการแยกโฮสต์หน้าเว็บและ API ให้ตั้งค่าดังนี้

- ใส่ origin ของ API ใน `window.electionAPIBase` ใน `server-config.js` ของไฟล์หน้าเว็บ
- ตั้ง `ELECTION_PUBLIC_URL` เป็น origin HTTPS ของ API และ `ELECTION_WEB_ORIGIN` เป็น origin HTTPS ของ GitHub Pages ในสภาพแวดล้อมของเซิร์ฟเวอร์ พอร์ตเริ่มต้นคือ 8081 เปลี่ยนได้ด้วย `ELECTION_PORT` หากโฮสต์กำหนดให้เปิดฟังนอก loopback ให้ตั้ง `ELECTION_BIND` ตามระบบโฮสต์ และให้ตัวรับ HTTPS ส่ง Host ของ API เดิมมาที่เซิร์ฟเวอร์
- ใช้พื้นที่เก็บข้อมูลถาวรสำหรับ `election.private.sqlite` และสำรองไฟล์นี้เพื่อเก็บทะเบียน การตั้งค่า รูป และคะแนน สามารถระบุที่ตั้งไฟล์ด้วย `ELECTION_DATA_FILE` ไฟล์ SQLite และไฟล์นำเข้าทะเบียนเป็นข้อมูลส่วนตัว จึงอยู่ในรายการยกเว้นของ Git

การตั้งค่า คะแนน และผู้สมัครที่เคยบันทึกในพรีวิวเก่าหรือใน Firebase แยกจาก SQLite ชุดใหม่นี้ หากต้องการเพิ่มทะเบียนจากไฟล์เดิมภายหลัง ให้เตรียมไฟล์ด้วย `node functions/prepare-roster.js` หรือนำเข้าจากเมนู **ทะเบียนและการใช้สิทธิ์** ก่อนเปิดหีบ
